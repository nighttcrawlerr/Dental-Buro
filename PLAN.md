# Dental Buro Clinic — план разработки сайта

Рабочий документ. Движемся сверху вниз, по одному шагу за раз. У каждого шага есть
список файлов и критерий готовности — пока критерий не выполнен, к следующему шагу не
переходим.

---

## Принятые решения

| Решение | Выбор | Причина |
|---|---|---|
| Стек | Next.js 16 (App Router) + TypeScript + Tailwind v4 | Многостраничник с серверным рендером, нормальный SEO, серверные роуты для заявок, запас на CMS и личный кабинет |
| Дизайн-основа | Стайлгайд Integrated Biosciences (перенесу в `DESIGN.md` на шаге 1.1) | Плоские поверхности, тонкие линии, крупная типографика, один акцент, много воздуха |
| Типографика | Cormorant Garamond (дисплей) + Onest (текст и UI) + JetBrains Mono (метки) | Serif даёт премиальную ноту под интерьер с мрамором и золотом, у всех трёх есть кириллица |
| Контент | Типизированные файлы в репозитории | Быстрый старт, ноль инфраструктуры; переезд на CMS позже без переписывания вёрстки |
| Языки | Только русский | Роутинг закладываем так, чтобы второй язык добавлялся без переделки |
| Акцент | Sky `#3F5F7E` | Знак синий; бронза осталась в палитре, но действия больше не красит |
| Приём заявок | Telegram-бот через серверный route handler | Токен не попадает в браузер |

### Палитра

Снята пипеткой с борда концепции интерьера. Sky Silver приведён по балансу белого —
скрин снят при холодном свете.

| Токен | HEX | Роль |
|---|---|---|
| `cream` | `#F3EEE8` | Канва светлых секций |
| `paper` | `#FFFFFF` | Карточки |
| `linen` | `#D9CBC2` | Тёплая альтернативная карточка |
| `sand` | `#DBD1C7` | Заливки, плашки |
| `stone` | `#C6BCB2` | Вторичный текст на тёмном (6.5:1 на эспрессо) |
| `espresso` | `#3E342B` | Канва тёмных секций |
| `ink` | `#241E19` | Основной текст, подвал |
| `sky` | `#3F5F7E` | Холодная секция, Sky Silver G 0859 |
| `graphite` | `#6B5F53` | Вторичный текст на светлом (5.4:1) |
| `bronze` | `#825A34` | **Акцент** на светлом (5.3:1) |
| `bronze-soft` | `#CFA36A` | **Акцент** на тёмном (5.3:1 на эспрессо) |

Дисциплина акцента: бронза живёт только на микроповерхностях — стрелки 40×40, точки
тегов 6px, активный пункт меню, подчёркивания. Никаких больших бронзовых заливок и
градиентов. Sky Silver — это **поверхность**, а не второй акцент.

Ритм страницы: кремовая канва → эспрессо → Sky Silver → кремовая.

## Как мы работаем

1. Я беру один шаг, делаю его целиком, показываю результат.
2. Ты смотришь в браузере на `localhost:3000`, говоришь правки.
3. Правим, коммитим, идём дальше.
4. Отмечаем шаг галочкой прямо в этом файле.

Отдельные экраны и компоненты правим сразу, а не копим — переделывать сетку на
восьми готовых страницах дороже, чем на одной.

## Этап 1. Дизайн-система и оболочка сайта ✅

## Этап 5. Юридические требования

Для медицинской организации это не формальность — за это штрафуют. Выношу отдельным
этапом, чтобы не потерялось. **Финальные тексты должен согласовать юрист клиники**, я
подготавливаю каркас и места под реквизиты.

- [ ] **5.1 — Лицензия.** Номер, дата, орган выдачи, скан — в подвале и на `/about`.
- [ ] **5.2 — Сведения об организации.** Полное наименование, ИНН, ОГРН, адрес, режим работы.
- [ ] **5.3 — Прейскурант.** Публикация обязательна.
- [ ] **5.4 — Сведения о врачах.** ФИО, специальность, образование, квалификация, стаж.
- [ ] **5.5 — Предупреждение о противопоказаниях.** «Имеются противопоказания, необходима консультация специалиста» — на всех страницах с описанием услуг.
- [ ] **5.6 — Персональные данные.** Политика, форма согласия, чекбокс в формах, уведомление Роскомнадзора.
- [ ] **5.7 — Плашка cookie.** Только если подключаем аналитику.

⚠️ **Вопрос к обсуждению:** персональные данные граждан РФ должны храниться на серверах
в России. Vercel и Telegram этому не соответствуют. Варианты:
хостинг в РФ (Timeweb Cloud, Selectel, Yandex Cloud) плюс запись заявок в базу в РФ,
а Telegram использовать только как уведомление без персональных данных, со ссылкой на
карточку заявки. Решаем до деплоя — от этого зависит инфраструктура.

## Что нужно от клиники

Список для запроса, чтобы заглушки заменялись по мере поступления, а не все в конце.

**Срочно, блокирует запуск:**
- Реквизиты: полное наименование, ИНН, ОГРН, юридический и фактический адрес
- Лицензия: номер, дата, орган выдачи, скан
- Телефон, почта, ссылки на мессенджеры, график работы
- Прайс-лист

**Нужно для наполнения:**
- Фото врачей и данные: ФИО, должность, образование, стаж, сертификаты
- Фото интерьера и оборудования
- Работы «до/после» с письменным согласием пациентов на публикацию
- Отзывы или доступ к карточке на Яндекс.Картах
- Исходники логотипа, если есть в векторе

**Организационное:**
- Кто получает заявки в Telegram — создать чат или канал и добавить бота
- Кто согласует юридические тексты
- Домен: есть или регистрируем
